# Sample HookProof reports

The JSON and HTML files in this folder were generated by **actually running**
the CLI against the local lab. They are provided as labelled sample output.

| File | Mode | Result |
| --- | --- | --- |
| `sample_report_vulnerable.json` | vulnerable | `FAIL` – 9 findings, highest severity `CRITICAL` |
| `sample_report_vulnerable.html` | vulnerable | same run, rendered as a standalone HTML page |
| `sample_report_secure.json` | secure | `PASS` – 11/11 |
| `sample_report_secure.html` | secure | same run, rendered as a standalone HTML page |

Both runs used the full 11-test core suite and 21 HTTP requests.

To reproduce:

```powershell
$env:HOOKPROOF_WEBHOOK_SECRET="demo-webhook-secret"
$env:HOOKPROOF_TEST_TOKEN="demo-test-token"

# terminal 1
hookproof lab serve --mode vulnerable --host 127.0.0.1 --port 8010

# terminal 2
hookproof scan --target http://127.0.0.1:8010/webhooks/payment --suite core `
  --report reports/report_vulnerable.json --html reports/report_vulnerable.html
```

Then repeat with `--mode secure --port 8011` for the passing run.

The reports contain only synthetic IDs, response metadata and before/after
state. No signing secret or test token is ever written to a report. The HTML
files have no external assets, scripts or CDN dependencies, so they can be
opened offline or attached to a report.
