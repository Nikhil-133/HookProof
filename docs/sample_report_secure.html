Limitations
  • EffectProof requires the target to expose a restricted test-state interface (the HookProof lab provides one). Internal effects of an arbitrary API cannot be observed without suitable instrumentation.
  • HookProof only scans explicitly allowed hosts; the default allow-list is loopback.
  • The MVP includes a single event type (payment.succeeded) and a single 'core' suite.
  • Timing/race findings are probabilistic: a clean concurrent test does not prove the absence of a race under all conditions.
